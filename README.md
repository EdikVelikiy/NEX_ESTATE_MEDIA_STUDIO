# NEX ESTATE Media Studio 2.2

Локальный браузерный редактор фотографий и видео для подготовки материалов NEX ESTATE. Сборка Node.js и `npm install` не требуются: оболочка работает как PWA, а небольшой локальный Python-сервер включает проверку медиа и встроенный кодировщик настоящего MP4 H.264/AAC.

## Быстрый запуск в Windows

1. Распакуйте весь комплект в отдельную папку, сохранив структуру файлов.
2. Дважды щёлкните `START_WINDOWS.cmd`.
3. Откроется адрес `http://127.0.0.1:8765/` в браузере по умолчанию.
4. Не закрывайте окно сервера во время работы. Для остановки нажмите `Ctrl+C`.

Запускатель ищет сначала команду `py`, затем `python`. Если Python не установлен, установите бесплатный Python 3.12 через Microsoft Windows Package Manager:

```powershell
winget install --id Python.Python.3.12 -e
```

После установки откройте папку проекта в PowerShell и выполните:

```powershell
py -3 nex_server.py --port 8765 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8765/`. Не запускайте `index.html` напрямую через `file://`: service worker, PWA и часть браузерных API требуют локального HTTP-адреса.

Рекомендуются актуальные Microsoft Edge или Google Chrome. Проверка выпуска выполнена в Microsoft Edge.

## Установка как приложения Windows

1. Запустите редактор через локальный сервер.
2. Откройте меню Edge или Chrome.
3. Выберите «Приложения» → «Установить NEX ESTATE Media Studio» либо значок установки в адресной строке.
4. После установки редактор можно открывать в отдельном окне. Локальный сервер всё равно должен быть доступен по адресу установки.

## Основные возможности

### Фото

- режим Light с быстрым адаптивным улучшением;
- режим Pro с 19 различимыми профилями и девятью ручными параметрами;
- анализ экспозиции, динамического диапазона, баланса белого и шума;
- сохранение исходных размеров и выбор между максимальным качеством и минимальным размером;
- быстрое прямоугольное и отдельное редактируемое выделение; у гибкой рамки доступны углы, стороны, перемещение и поворот;
- обработка нескольких фотографий и пакетная выгрузка ZIP без перезаписи одинаковых имён.

### Видео

- Light-улучшение и Pro-пресеты с ручной цветокоррекцией;
- программная 2D-стабилизация с уровнями интенсивности и предупреждениями;
- умный поиск кадров для обложки и экспорт в выбранном соотношении сторон;
- пользовательские разрешение, FPS и битрейт;
- «Фото каждую секунду» для всего ролика: до 60 кадров, автоматическое увеличение интервала для длинных видео, предварительное предупреждение, обработка пакетами и проверяемый ZIP;
- запись озвучки, пауза, сохранение и микширование с исходным звуком;
- локальное распознавание речи Whisper после загрузки модели;
- редактирование, стилизация и анимация субтитров;
- финальный экспорт с цветом, стабилизацией, логотипом, аудио и субтитрами;
- настоящий MP4 с H.264/AAC через комплектный локальный FFmpeg; расширение никогда не подменяет реальный контейнер;
- проверка контейнера, кодеков, аудио- и видеодорожек, длительности и декодируемого контрольного кадра перед скачиванием;
- прогресс, отмена операций и восстановление интерфейса после отмены.

## Работа с данными

Фото и покадровый рендер выполняются в браузере. Для проверки и финального MP4 браузер передаёт промежуточный файл только локальному серверу `127.0.0.1`; сервер запускает комплектные `ffprobe`/`ffmpeg`, хранит временные данные в каталоге ОС и удаляет их после ответа. Пользовательские медиа не отправляются во внешнюю сеть. Итоговый файл появляется на диске только при явной команде скачивания.

Исключение — модуль Whisper: при первом запуске браузер загружает JavaScript-модуль и бесплатную модель из интернета. Затем браузер может использовать локальный кэш. Распознавание выполняется в браузере.

Перед большой обработкой закройте лишние вкладки. Длинные ролики, 4K-видео и максимальные параметры качества могут потребовать много оперативной и видеопамяти.

## Ограничения

- Браузер должен поддерживать `MediaRecorder` с WebM для промежуточного потока. Финальный MP4 не зависит от браузерной поддержки записи MP4: его создаёт комплектный локальный FFmpeg 8.1.2.
- Стабилизация является браузерной 2D-коррекцией смещения. Она не заменяет профессиональную оптическую стабилизацию, данные гироскопа или полноценный optical flow.
- За один запуск «Фото каждую секунду» создаётся не более 60 кадров. Для длинных видео интервал рассчитывается автоматически; в проверке 65-секундный ролик дал ровно 60 кадров в восьми пакетах.
- Экспорт проверен на роликах до 8,2 секунды и 640 px по длинной стороне; многочасовые ролики и полный 4K-стресс-тест не выполнялись, практический предел зависит от RAM, GPU и свободного места.
- Сквозная проверка реальной модели Whisper не выполнялась, поскольку она требует внешней загрузки модели. Интерфейс источников, языка, отмены и субтитров проверен отдельно.
- Запись озвучки в автоматическом тесте проверялась через разрешённый тестовый аудиопоток, а не через физический микрофон конкретного компьютера.
- После первого кэширования оболочка редактора открывается офлайн, но первичная загрузка модели Whisper требует сети.

## Структура комплекта

- `index.html` — основное приложение и медиаконвейер;
- `photo-engine.js` — адаптивная обработка фотографий;
- `studio-upgrade.js` — расширенные элементы управления и состояние интерфейса;
- `studio-upgrade.css` — темы, адаптивная компоновка и новые компоненты;
- `nex_server.py` — локальный сервер, проверка медиа и транскодирование MP4;
- `vendor/ffmpeg/` — комплектные `ffmpeg`/`ffprobe`, лицензия и уведомление об источнике;
- `vendor/webm-duration.js` — локальная коррекция метаданных длительности WebM;
- `service-worker.js` и `manifest.webmanifest` — PWA и офлайн-кэш оболочки;
- `assets/` — иконки и фирменные знаки;
- `qa/` — автоматический сценарий и артефакты приёмочной проверки;
- `TEST_REPORT.md` — результаты проверки выпуска;
- `RELEASE_NOTES.md` — перечень реализованных изменений;
- `START_WINDOWS.cmd` — локальный запуск в Windows.

## Диагностика запуска

- Если порт `8765` занят, остановите другую программу на этом порту или запустите сервер на другом порту и откройте соответствующий адрес.
- Если браузер показывает старую версию, закройте установленное PWA-окно, обновите страницу с `Ctrl+F5` и запустите снова.
- Если MP4 недоступен, убедитесь, что приложение запущено через `START_WINDOWS.cmd`, а файлы `vendor\ffmpeg\bin\ffmpeg.exe` и `ffprobe.exe` не удалены антивирусом.
- Состояние локального кодировщика можно проверить по адресу `http://127.0.0.1:8765/api/health`.
- Если экспорт не запускается, проверьте поддержку `MediaRecorder`, разрешение на микрофон и свободную память браузера.

Подробная проверка выпуска приведена в `TEST_REPORT.md`.
