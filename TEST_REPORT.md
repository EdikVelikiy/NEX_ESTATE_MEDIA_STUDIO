## Статус публичной PWA и физических устройств

Публичный URL проекта и доступ к установленной с него актуальной PWA не были предоставлены и не обнаружены в текущем архиве. Поэтому не выполнены:

- публикация этой сборки на реальном GitHub Pages;
- обновление установленной PWA с публичного адреса;
- экспорт и повторная загрузка результата именно на публичном адресе;
- проверка на физическом iPhone и физическом Android.

Временный статический тестовый хост использовался только для предварительной браузерной проверки и не считается тестом публичной PWA.

## Техническое ограничение MP4

Настоящий MP4 в этой полностью браузерной архитектуре доступен только там, где MediaRecorder нативно поддерживает контейнер MP4 с подходящими кодеками. На проверенном Chrome это подтверждено. Для браузеров без такой поддержки результатом автоматического режима является настоящий WebM. Для обязательного универсального MP4 потребуется отдельно согласованный production-сервис по HTTPS; он не входит в эту сборку.
